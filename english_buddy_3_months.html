Cách Đưa Website "Lười English" Lên Mạng Để Dùng Mọi Lúc Mọi Nơi

Chỉ mất chưa đầy 3 phút với 2 cách cực kỳ đơn giản dưới đây.

Cách 1: Nhanh nhất quả đất với Netlify Drop (Không cần code)

Thích hợp nếu mày muốn có link truy cập ngay trong 10 giây.

  1. Lưu toàn bộ code của trang này thành một file tên là index.html.
  2. Truy cập trang web miễn phí: app.netlify.com/drop
  3. Kéo thả file index.html của mày vào khung trên trang web đó.
  4. Netlify sẽ ngay lập tức tạo cho mày một đường link web riêng (ví dụ: luoi-english.netlify.app). Xong!

Cách 2: Lâu dài & chuyên nghiệp với GitHub Pages

Dành cho việc lưu trữ lâu năm không sợ mất link.

  1. Tạo một tài khoản miễn phí trên GitHub.com.
  2. Tạo một Repository mới (đặt tên ví dụ là luoi-english), chọn chế độ Public.
  3. Tải file index.html lên repository đó.
  4. Vào phần Settings -> Pages -> ở mục Build and deployment chọn nguồn là main branch rồi bấm Save.
  5. Sau 1 phút, GitHub sẽ cấp cho mày link web dạng: username.github.io/luoi-english.
